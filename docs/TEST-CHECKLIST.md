# VMware(Rocky 9.8) 확인표

`docs/DEPLOY.md` 대로 설치한 뒤, 실제 nmcli로 하나씩 확인합니다. 결과 칸에 ✅ / ❌ 와 메모를 적으세요.

## 꼭 지킬 규칙

- 실험은 **2번 카드**(예: `ens224`)로만 합니다. 아래에서 `ens224` 는 1단계 `nmcli device` 로 확인한 2번 카드 이름으로 바꿔 읽으세요.
- **1번 카드**(예: `ens160`)의 프로파일은 끄거나·지우거나·고치지 않습니다. (SSH·인터넷이 끊길 수 있음)
- 프로파일을 만들 때 "연결할 장치"는 항상 **ens224** 를 고릅니다. ("아무 장치나"는 1번 카드에 붙을 수 있음)
- 고정 IP는 DEPLOY 1번에서 확인한 2번 카드 대역을 씁니다. (아래 예: `192.168.56.0/24`)
- 화면 아래 **실행 기록** 패널을 펼쳐 두면, 앱이 실제로 어떤 nmcli 명령을 실행했는지 같이 볼 수 있습니다.

## 0. 시작 전 기록

| 항목 | 명령 | 값 |
| --- | --- | --- |
| NetworkManager 버전 | `nmcli --version` | |
| Node.js 버전 | `node -v` | |
| 2번 카드 이름 / 대역 | `nmcli device`, `ip -4 addr show ens224` | |
| 권한 | `sudo -u nmweb nmcli general permissions` (두 줄 yes) | |
| 테스트 | `cd /opt/nm-web && npm test` (fail 0) | |

## 2. 보안 (S-01 ~ S-10)

가상머신 터미널에서 확인합니다.

| ID | 확인할 것 | 명령 | 기대 결과 | 결과 |
| --- | --- | --- | --- | --- |
| S-01 | 127.0.0.1 에만 열림 | `ss -ltnp \| grep 8080` | `127.0.0.1:8080` 만 (0.0.0.0·`*` 아님) | |
| S-01 | 밖에서 접속 불가 | Windows 브라우저에서 `http://<가상머신 IP>:8080` | 연결 안 됨 | |
| S-04 | 토큰 없으면 거부 | `curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:8080/` | `401` | |
| S-02 | 가짜 Host 거부 | `curl -s -o /dev/null -w '%{http_code}\n' -H 'Host: evil.example.com' http://127.0.0.1:8080/` | `403` | |
| S-03 | 다른 Origin 거부 | 아래 명령 (토큰은 journal 에서) | `403` | |
| S-05·06 | 정해진 명령만 | 화면 실행 기록의 명령이 모두 `connection show/add/modify/up/down/delete/clone`, `device status`, `general status` 뿐 | 그 밖의 명령 없음 | |
| S-08 | 비밀값 미노출 | 실행 기록·응답에 `-s` 옵션이 없음 | 없음 | |
| S-10 | 외부 파일 없음 | 브라우저 개발자 도구(F12) → 네트워크 탭 | 모든 요청이 `127.0.0.1:8080` 으로만 | |

S-03 확인 명령:

```bash
TOKEN=$(sudo journalctl -u nm-web -n 50 --no-pager | grep -o 'token=[A-Za-z0-9_-]*' | tail -1 | cut -d= -f2)
curl -s -o /dev/null -w '%{http_code}\n' -X POST -H "Cookie: nmweb_token=$TOKEN" \
  -H 'Origin: http://evil.example.com' -H 'Content-Type: application/json' -d '{}' \
  http://127.0.0.1:8080/api/connections
```

## 3. 맥(가짜 nmcli)과 다를 수 있어 꼭 볼 것

가짜 nmcli는 진짜 nmcli 1.46을 흉내 냈지만, 아래는 실제 장비에서 다를 수 있습니다. 다르면 메모해 주세요.

| 확인할 것 | 보는 곳 |
| --- | --- |
| 빈 값이 상세 화면에 `—` 로 나오는지 (`--` 같은 글자가 그대로 보이면 알려 주세요) | 상세 화면 게이트웨이·MAC 칸 |
| MTU 가 비어 있을 때 "자동" 으로 나오는지 | 상세 화면 유선 칸 |
| IPv6 주소(콜론 포함)가 깨지지 않는지 | `lo` 상세의 `::1/128` |
| 편집에서 게이트웨이를 비우고 저장하면 지워지는지 | `nmcli -g ipv4.gateway connection show lab-lan` |
| MTU 를 비우고 저장하면 자동(`auto`)으로 돌아가는지 | `nmcli -g 802-3-ethernet.mtu connection show lab-lan` |
| 오류 문구와 종료 코드가 표(SPEC 8장)와 같은지 | 실패한 동작의 알림 상자 |
